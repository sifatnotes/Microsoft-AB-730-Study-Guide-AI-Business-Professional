## Detailed Study Notes

### Generative AI Fundamentals

Understand how generative AI produces responses from instructions and available context. For Copilot, context can include the application, organizational information, files, and web information.

Focus on the difference between:

- **Prompt:** Instruction given to an AI system.
- **Chat:** Interactive conversation with AI.
- **Agent:** AI configured for a particular purpose, often with instructions, knowledge, and capabilities.
- **Notebook/Page:** Microsoft 365 experiences for organizing and working with information.

### Prompt Engineering

A useful business prompt should clearly communicate:

1. **Goal** — What should Copilot accomplish?
2. **Context** — What business situation matters?
3. **Source** — Which files, information, or references should be used?
4. **Output** — What format should the result have?
5. **Constraints** — What limitations or requirements apply?

Example:

> "Summarize the attached quarterly report for senior management. Highlight three business risks and three recommended actions. Use concise bullet points."

### Responsible AI

AI output should not automatically be treated as correct.

Learn to identify:

- Fabricated information
- Incorrect or unsupported statements
- Prompt injection
- Excessive dependence on AI
- Sensitive-data exposure

For important business decisions, verify facts, review citations, and maintain human oversight.

### Copilot and Business Content

Practice using Copilot to:

- Draft emails
- Create documents
- Summarize information
- Prepare presentations
- Analyze business content
- Generate management summaries
- Support meetings
- Organize collaborative information

## Practical Examples / Labs

Practice these scenarios using Microsoft 365 where available:

1. Write a professional email from a short set of requirements.
2. Summarize a long business document.
3. Ask Copilot to create a management briefing.
4. Refine a weak prompt into a structured prompt.
5. Compare AI-generated content against its source.
6. Use Copilot in Word, Excel, PowerPoint, Teams, and Outlook.
7. Create or configure an appropriate Copilot agent.
8. Identify sensitive information that should not be exposed in a prompt.
9. Organize useful information in a notebook or Copilot Page.
10. Review an AI response for accuracy and unsupported claims.

Microsoft provides a free AB-730 Practice Assessment; it is intended to help identify knowledge gaps and understand representative question styles, not to reproduce actual exam questions.

## Common Mistakes

- Memorizing features without understanding use cases
- Writing vague prompts
- Ignoring context and source selection
- Trusting AI-generated information without verification
- Overlooking sensitive-data risks
- Confusing chat functionality with agent functionality
- Studying only theory without hands-on Microsoft 365 practice
- Using outdated exam objectives

## Exam-Day Tips

- Read each scenario carefully.
- Identify the business goal before selecting an AI feature.
- Eliminate options that introduce unnecessary data or security risks.
- Consider context, permissions, and source information.
- Do not assume AI-generated content is automatically accurate.
- Use the exam sandbox beforehand to become familiar with the interface.
- Manage your time and mark difficult questions for later review.
